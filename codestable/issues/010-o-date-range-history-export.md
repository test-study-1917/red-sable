# 聊天记录按日期查询与导出

打开聊天记录不再自动翻到房间起点。手机收起筛选时，点「今天」「昨天」或「最近 7 天」直接读取该时段；展开筛选或使用桌面时，设好日期（可精确到分钟）再点「查询」。预览和 TXT、Markdown、HTML 导出使用同一批结果。日期留空时可立即导出已载入记录，也可主动读取全部历史。

桌面入口仍在房间搜索侧栏。手机从房间打开「搜索消息」后，在标题栏右侧进入「聊天记录」；退出后保留原搜索。只有明确限定到一个已加入房间的搜索显示入口，未限定房间、空间和多房间搜索不显示。

```text
聊天记录                                                        关闭
[今天] [昨天] [最近 7 天] [开始时间 日期] [结束时间 日期] [查询 / 停止读取]
[搜索聊天记录] [发送者] [消息类型]
查询状态 · 匹配条数
─────────────────────────────────────
消息列表
─────────────────────────────────────
                   [导出 N 条 ▾]
```

手机默认显示日期摘要与三个快捷日期；不限日期时显示「不限日期」。点独立的「筛选」行展开详细条件，同一组快捷日期留在原位：

```text
[日期摘要                                  筛选 ⌄]
[今天] [昨天] [最近 7 天]          [读取全部历史 / 查询 / 停止读取]
[开始时间 · 日期和分钟]            [结束时间 · 日期和分钟]
```

- 未查询的日期不沿用上次结果；读取中显示一处进度。失败或停止后，如已有匹配结果，提供「仅导出已读取结果」，并在文件注明范围未读完。不选日期时，主时间线可能缺最早或最新记录，导出时分别注明。
- 开始、结束分钟均包含在范围中；只选起点时到本次查询时刻，只选终点时从最早可读记录起。快捷日期按设备本地日历计算。
- 桌面日期控件同排，窄弹窗按顺序换行。手机首行并排显示快捷日期和固定位置的读取动作，第二行是等宽的起止日期按钮，标签与完整日期值分行显示在按钮内。
- 手机摘要显示实际起止时间；同日省略第二个日期，跨日保留两端日期，只选一端则标明「从……起」或「截至……」。收起不改变筛选或发起请求。发起有效查询时立即收起，收起时仍显示待查询、读取或未读取完的状态，并可停止读取；重新展开编辑不会被查询完成再次收起。
- 收起时点快捷日期会保留关键词、发送者和消息类型，切换日期时只展示新时段的结果。展开时点快捷日期先填入起止时间，不立即查询。
- 快捷日期按下时立即变色，所选时段与快捷项完全一致时保留高亮；自定义时间偏离该范围时取消高亮。日期选择器打开时标记对应按钮。点「查询」后仍可停止读取；进度与完成提示使用同一条状态栏。
- 「消息类型」提供全部消息、文件、图片与视频、含链接，不触发新的历史请求。原「媒体、文件和链接」侧栏及原消息、图片/视频预览保留；导出不下载附件。
- 手机「发送者」和「消息类型」的选项贴着各自的按钮，在聊天记录弹窗内显示，不被可滚动的筛选区裁切。下方空间不足时改在按钮上方打开。

## 关键实现选择

事件焦点时间线遇到线程回复会自动进入线程，分页应答也可能早于时间线消息补丁。导出改用现有 Matrix 时间定位接口与独立的房间历史游标：定位到结束时间之后，从该处反向分页，直到读到开始时间之前的锚点或最早可读事件。每页直接携带导出候选消息，不消费主时间线的分页状态，也不改变聊天位置。时间定位失败时标为未读完，不改为从最新记录盲翻。

手机搜索页用房间 ID 保持作用域，复用同房间已有的时间线缓存与同一个导出窗口。缓存不是完整历史；没有缓存时，可查询日期范围或主动读取全部历史。手机返回先关闭筛选下拉或媒体预览，再关闭导出窗口并回到原搜索。

## 验收

- 日期查询从目标日期的游标开始，包含开始和结束分钟，读到边界就停止。
- 不操作日期或查询时，不发历史分页请求；不选日期也能下载已载入记录。
- 合并后的聊天记录预览与导出一致；读取取消、失败或切换日期后，过期页面不能覆盖现有结果。
- 浏览器验证日期选择、消息类型、导出菜单和下载，并确认未新增主聊天时间线订阅或分页。
- 检查常规宽度下日期控件同排、窄容器下自然换行且没有横向溢出；开始、结束日期弹层均能打开并确认。
- 真实点击快捷日期与查询，验证按住状态、实际日期范围与选中态一致、弹层开合、无高度变化的读取反馈，以及查询完成提示。
- 在真实手机视窗验证标题栏入口、同房间缓存和查询、日期浮层、图片预览、下载菜单与返回顺序；清除房间条件后入口消失。桌面仍从原侧栏进入。
- 检查手机展开后的日期控件恰为两行，动作从「读取全部历史」切换到「查询」和「停止读取」时位置不变，起止日期值不截断且能分别打开弹层。
- 检查手机日期摘要的空范围、同日、跨日与单边范围；验证开合保留关键词、发送者和消息类型，不发额外请求，读取中重新展开编辑后不会被完成状态强制收起。
- 不展开手机筛选，分别点三个快捷日期，验证一次点按即查询对应时间范围；读取中切换后只保留最后所选时段的结果。
- 触屏点选两个筛选下拉，检查对齐、弹窗边界与选中状态；验证空间不足时向上展开，Esc 或返回只收起下拉。

- `pnpm check`、Core 的 WASM 开发构建及前端 Vite 构建通过。生成的浏览器截图覆盖日期选择器、筛选结果和导出菜单。
